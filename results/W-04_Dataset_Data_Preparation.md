\# Dataset and Data Preparation



\## 1. Dataset



This project uses the Case Western Reserve University (CWRU) Bearing Data Center dataset.



Official source:

https://engineering.case.edu/bearingdatacenter/welcome



The selected data consist of Drive-end (DE) acceleration signals collected under four motor loads:



\- 0 HP

\- 1 HP

\- 2 HP

\- 3 HP



The dataset includes normal baseline signals and three fault types:



\- 0.007" inner race fault

\- 0.007" ball fault

\- 0.007" outer race fault at the 6:00 position



A total of 16 MATLAB `.mat` files were used.



\## 2. Data Sampling



The selected Drive-end signals use a sampling rate of 12 kHz.



All selected normal and fault files use the same sampling rate, so no resampling was required.



The Drive-end signal is read from the corresponding `X\*\*\*_DE_time` variable in each MATLAB file.



\## 3. Windowing



Each raw Drive-end signal is divided into windows of 1024 samples.



For normal 0 HP data:



\- Training: 70%

\- Validation: 15%

\- Test: 15%



The split is chronological.



Training windows use a stride of 512 samples.



Validation and test windows use a stride of 1024 samples and are non-overlapping.



For normal 1 HP, 2 HP and 3 HP data:



\- First 10% is used as calibration data.

\- Remaining 90% is used as test data.

\- Window stride is 1024 samples.



Fault data are assigned to the test split corresponding to their motor load.



\## 4. Normalization



The main pipeline calculates normalization statistics only from the training windows of normal 0 HP data.



The calculated statistics are:



\- Mean: 0.0125434473

\- Standard deviation: 0.0723953544



They are saved in:



`data/processed/train_stats.npz`



Separate normalization statistics are not used in the main pipeline.



For the condition-specific ablation, separate statistics were also calculated for normal test data at each load.



\## 5. Processed Dataset



The processed data are stored in `.npz` files under:



`data/processed/`



Each file contains:



\- `X`

\- `y`

\- `fault_type`

\- `fault_size`



The main processed files are:



\- `load0_train.npz`

\- `load0_val.npz`

\- `load0_test.npz`

\- `load1_calibration.npz`

\- `load1_test.npz`

\- `load2_calibration.npz`

\- `load3_calibration.npz`

\- `load3_test.npz`

\## 7. Signal Distribution Across Loads



RMS and FFT analysis was performed on the normal test signals.



| Load | RMS mean | RMS std | FFT peak frequency |

|---:|---:|---:|---:|

| 0 HP | 0.0738543678 | 0.0030940480 | 1031.25 Hz |

| 1 HP | 0.0663298015 | 0.0033462278 | 1066.41 Hz |

| 2 HP | 0.0642252685 | 0.0027801269 | 2097.66 Hz |

| 3 HP | 0.0657616621 | 0.0028427154 | 2097.66 Hz |



The RMS distribution changes across motor loads. The average RMS decreases from 0 HP to 2 HP and increases slightly at 3 HP.



The dominant FFT peak also changes with load, from approximately 1.03 kHz at 0 HP to approximately 2.10 kHz at 2 HP and 3 HP.



These results indicate that the signal distribution is affected by the operating load. Therefore, the load condition should be considered when evaluating the robustness of the anomaly detection model.



\## 8. Reproducibility

`data/raw/CWRU/`



The preprocessing script is:



`src/data/prepare.py`



Run from the project root:



python src\\data\\prepare.py



The script generates the processed `.npz` files under:



`data/processed/`



Condition-specific statistics are generated by:



`src/data/condition_stats.py`



RMS and FFT analysis is generated by:



`src/data/load_analysis.py`
